# Dev Notes

Two PDF guides plus their LaTeX sources, published with GitHub Pages.

- **The FFmpeg Codebase: A Guided Tour** -- `FFmpegCodebase.pdf`
- **A Practical Path into Low-Level Programming** -- `LowLevelRoadmap.pdf`

## Site

<https://1clan.github.io/dev-notes/>

## Rebuild the PDFs

Both documents are self-contained and compile with plain `pdflatex`:

```sh
pdflatex FFmpegCodebase.tex
pdflatex LowLevelRoadmap.tex
```

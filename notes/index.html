How these notes are organised

Each page follows the same arc: a mental model first, then a map of the important pieces, then concrete exercises or a reading order. Code snippets are kept short so the shape of the system stays visible.

New to this? Start with Low-Level Programming stages 1–3, then read the FFmpeg notes. The two are designed to meet in the middle at a small decode-and-render program.
